Software developer by trade, ABB robot whisperer by former profession, and professionally curious about InfoSec, SIGINT, OSINT, Social Engineering and IT forensics. I want to know how things work — and why they do what they do. So I regularly stumble onto something new, usually followed by a new rabbit hole to fall into. ot2i7ba ... that's me.

In my spare time I build small tools on my own — for fun, for the job, or on commission. Ever since AI became everyone's tool of choice, there are suddenly a lot more programmers out there. I don't mind — quite the opposite. AI is a great tool for time-critical tasks, but it should be used transparently. Practicing what I preach: I use it for brainstorming, translations, documentation and code reviews. Fair's fair.
